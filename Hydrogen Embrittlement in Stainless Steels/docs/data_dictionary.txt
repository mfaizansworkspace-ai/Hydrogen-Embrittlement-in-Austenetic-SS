# Data dictionary

One record is one reported test condition and one property.

| Column | Meaning |
|---|---|
| `record_id` | Unique id: source, table, row |
| `source_id` | Key into the source list |
| `source_short` | Author and year |
| `alloy` | Alloy designation, standardised |
| `heat` | Heat or cast id where reported |
| `material_family` | Grouping used for analysis |
| `product_form` | plate, bar, sheet, tube, weld |
| `is_weld` | Gauge section contains weld metal (yes/no) |
| `zone` | base metal / weld metal / HAZ / fusion line / whole joint |
| `weld_process` | GTAW, GMAW, PAW, laser |
| `filler_metal` | Filler wire designation |
| `ferrite_number` | Ferrite number of the weld metal, FN, where reported |
| `hydrogen_exposure` | gaseous in-situ or gaseous precharge |
| `h2_pressure_MPa` | Hydrogen gas pressure, MPa |
| `hydrogen_content_wppm` | Hydrogen content, wt ppm |
| `charging_time_h` | Precharging duration, hours |
| `test_temperature_K` | Test temperature, K |
| `test_temperature_C` | Test temperature, degrees C |
| `strain_rate_per_s` | Nominal strain rate, 1/s |
| `test_type` | tensile or SSRT |
| `property_name` | reduction of area, elongation, tensile strength, plastic strain to failure, notched tensile strength |
| `reference_environment` | air, helium, nitrogen, argon or uncharged |
| `property_reference` | Value in the reference environment, % or MPa |
| `property_h2` | Value in or after hydrogen, % or MPa |
| `relative_ratio` | property_h2 / property_reference; RRA when the property is reduction of area |
| `embrittlement_flag` | no measurable loss >= 0.95, moderate 0.80-0.95, significant < 0.80 |
| `ni_equivalent` | Nickel equivalent (Hirayama), wt %, computed where composition was reported |
| `derived` | Fields computed rather than reported by the source |
| `verified` | Independently re-extracted and matched (yes/no) |
| `notes` | Source table, test conditions and caveats |
